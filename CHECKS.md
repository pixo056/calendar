# Проверка поставки Calendar 0.1.0

Дата: 14 октября 2026 года.

- `build.cmd -o -B -ntp` — **BUILD SUCCESS**. Создан `target/calendar.jar` со встроенными Java-зависимостями.
- **10 тестов, 0 ошибок, 0 провалов, 0 пропусков.** Проверены запуск контекста, страница и ресурсы, CRUD, типы и даты, ошибки 400/404, справочник групп, разделение календарей и сохранение связей групп.
- `node --check src/main/resources/static/app.js` — успешно.
- `scripts/package.ps1 -SkipBuild` — создан `calendar-0.1.0.zip` и файл SHA-256.
- Состав ZIP проверен: только JAR, run.cmd, run.sh, START-HERE.md и scripts/java-env.cmd. Базы, кэша, исходников, токенов и локальных настроек в архиве нет.
- ZIP распакован в отдельную папку с пробелами в пути. `run.cmd` запустил приложение без исходников и Maven, страница вернула HTTP 200, справочник — 3065 групп. Чистая файловая H2-база создалась автоматически, список событий пустой.
- Скрипт `run.sh` прошёл синтаксическую проверку и запуск через Git Bash на Windows; страница вернула HTTP 200. Проверка на реальных macOS/Linux не выполнялась.
- Проверочные серверы остановлены. Существующая рабочая база и приложение разработчика при проверке не использовались и не перезапускались.
- В исходниках и инструкциях поставки отсутствуют персональные сетевые адреса. Отдельный сетевой режим запуска удалён; по умолчанию используется localhost.

Ранее адаптивная разметка проверена в браузере на ширине 320 и 390 пикселей: выбор группы, создание события и переключение календарей. Физический Android/iPhone не использовался.

Поставка требует установленную Java 25 или более новую совместимую версию. JDK/Java Runtime не входит в ZIP. Авторизации и развёртывания общего сервера нет; ограничения перечислены в README.md и START-HERE.md.
