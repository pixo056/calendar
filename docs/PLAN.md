# Следующие этапы

Это план развития, перечисленные ниже возможности ещё не реализованы.

1. Уточнить у преподавателя обязательные разделы мини-курсовой и критерии защиты. Основная группа — ТОП-105Б; доступен выбор других групп из справочника УУНиТ.
2. Согласовать роли: студент читает события, староста создаёт и изменяет, администратор управляет группой. Определить, кто подтверждает изменения.
3. Добавить пользователей, вход и проверку прав на сервере. При общей публикации подготовить HTTPS, настройки доступа и резервное копирование.
4. Для общего сервера подключить PostgreSQL, миграции схемы и конфигурацию окружения. После этого развернуть одно приложение, к которому обращается вся группа.
5. Добавить напоминания и выбор канала уведомлений; определить время и часовой пояс группы.
6. Добавить экспорт в iCalendar, просмотр недели и при необходимости повторяющиеся занятия.
7. Подготовить пояснительную записку: цель, задачи, сценарии, схема базы, архитектура, инструкция пользователя, проверки и выводы. Сопоставить её с шаблоном преподавателя.

Не следует начинать с микросервисов или отдельного фронтенд-сервера: текущая структура позволяет постепенно изучать Java, HTTP, базу данных и интерфейс в одном проекте.
