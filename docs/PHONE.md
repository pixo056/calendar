# Использование на Android и iOS

Календарь открывается как web-приложение в современном браузере телефона, например Chrome на Android или Safari на iOS. Установка отдельного APK или приложения из App Store не нужна.

## Телефон и компьютер в одной Wi-Fi-сети

1. Остановите уже запущенный календарь в IntelliJ красным квадратом или закройте запуск через Ctrl+C.
2. Запустите **Calendar (phone)** в списке конфигураций IntelliJ. Другой способ — двойной щелчок по `start-phone.cmd` в корне проекта.
3. Подключите телефон к той же Wi-Fi-сети, что и компьютер.
4. Откройте в браузере телефона адрес компьютера с портом 8080. Например, если IPv4 компьютера — `192.168.1.100`, адрес будет **http://192.168.1.100:8080**.
5. Компьютер и приложение должны оставаться включёнными. На самом компьютере продолжает работать http://localhost:8080.

IP может измениться после переподключения к сети. Посмотреть текущий адрес можно командой `ipconfig`: нужен IPv4 адаптера «Беспроводная сеть», а не адрес VPN. `localhost` на телефоне указывает на сам телефон, поэтому для подключения к компьютеру он не подходит.

При запуске через другую конфигурацию IntelliJ можно задать переменную окружения `SERVER_ADDRESS=0.0.0.0`. Обычная конфигурация Calendar / `start.cmd` по умолчанию доступна только с компьютера.

Если страница на телефоне не открывается, проверьте адрес, запущенный сервер, общую сеть и отсутствие изоляции клиентов гостевой Wi-Fi. Если Windows спрашивает о сетевом доступе Java, доступ нужен для вашей частной сети. Брандмауэр автоматически не менялся и не отключался. VPN также может влиять на доступ к локальной сети.

## Интерфейс

- На узком экране по умолчанию открыт список событий: названия и время легче читать.
- Кнопка календаря переключает на месяц. Сетка месяца прокручивается горизонтально внутри календаря.
- Кнопки и поля увеличены для касания, поля формы располагаются в один столбец на узком экране.
- Название группы сверху открывает поиск по официальному справочнику. Выбор запоминается на этом устройстве.

Размеры 320 и 390 пикселей проверяются в браузере компьютера. Это проверка адаптивной разметки, а не тест на физическом Android/iPhone.

## Через мобильный Интернет / из другой сети

Текущий способ предназначен для одной локальной сети. Для постоянного доступа вне Wi-Fi нужен общий сервер с HTTPS и учётными записями. Публикация в Интернете, проброс портов роутера и авторизация не настраивались. Сейчас любой с доступом к запущенному серверу может выбирать группы и менять события.
