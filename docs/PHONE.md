# Адаптивный интерфейс

На узком экране календарь по умолчанию показывает список событий. Кнопки и поля увеличены для касания; форма располагается в один столбец. Сетка месяца прокручивается внутри календаря, чтобы не сжимать названия событий. Выбор группы запоминается в браузере этого устройства.

Мобильная разметка проверена в браузере при ширине 320 и 390 пикселей. Это не проверка на физическом Android/iPhone.

В поставке 0.1.0 удалены специальный режим подключения к компьютеру разработчика, сетевые инструкции с адресами и отдельная конфигурация такого запуска. Приложение по умолчанию доступно только на компьютере запуска через localhost. Адаптивность интерфейса сохранена для дальнейшего размещения на отдельном сервере.

Для доступа с разных устройств через Интернет понадобится отдельное развёртывание с HTTPS и проверкой пользователей. Развёртывание сервера и авторизация не входят в текущую поставку.
