# Calendar — студенческий календарь УУНиТ

Web-приложение на Java / Spring Boot: календарь и список событий, контрольные, зачёты, экзамены, мероприятия и дедлайны. Есть поиск, фильтры, создание, редактирование, удаление и выбор из 3065 групп. Основная группа — ТОП-105Б. Интерфейс адаптируется к узким экранам.

## Получить готовый продукт

Откройте **Releases** этого репозитория и скачайте `calendar-0.1.0.zip`. Распакуйте целиком, установите Java 25 и запустите `run.cmd` в Windows или `sh run.sh` в macOS/Linux. Затем откройте **http://localhost:8080**.

В ZIP уже находится `calendar.jar` со всеми библиотеками. IntelliJ, Maven, Node.js и отдельная установка базы не нужны. Java в ZIP не включена. Полная инструкция для получателя — [START-HERE.md](START-HERE.md).

**GitHub Source code ZIP** содержит исходники. Для запуска без сборки нужен именно прикреплённый к выпуску `calendar-0.1.0.zip`.

## Разработка и сборка из исходников

Нужны **JDK 25**, доступ к Maven Central при первой сборке и примерно 200 МБ для библиотек и результата сборки. Отдельно устанавливать Maven не требуется: Maven Wrapper включён в репозиторий. Последующие запуски готового JAR не требуют загрузки зависимостей.

Windows:

```powershell
.\build.cmd
.\run.cmd
```

macOS / Linux:

```sh
export MAVEN_USER_HOME="$PWD/.mvn/user-home"
./mvnw package
sh run.sh
```

`build.cmd` и `mvnw package` запускают тесты и создают **target/calendar.jar**. `run.cmd` / `sh run.sh` собирают проект автоматически, если JAR ещё отсутствует. После изменений исходников выполните сборку снова. `start.cmd` — запуск из исходников через Maven во время разработки; `test.cmd` — отдельный запуск тестов.

Java выбирается из `JAVA_HOME` или `PATH`. Windows-скрипты также распознают JDK 25/26 в стандартной папке загрузок SDK IntelliJ `.jdks`. Конкретное имя SDK, поставщик и путь одного компьютера не требуются. Если выбрана старая Java, установите JDK 25 и исправьте `JAVA_HOME` / `PATH`.

### IntelliJ IDEA

1. **File → Open** → папка проекта / `pom.xml` → открыть как Maven-проект.
2. Выберите установленный **JDK 25** в Project SDK; Maven Importer и Runner — Project JDK.
3. В настройках Maven выберите **Use Maven wrapper**, дождитесь импорта.
4. Запустите конфигурацию **Calendar** или метод `CalendarApplication.main`.

Рабочая папка запуска — корень проекта; кодировка — UTF-8. Платные возможности Spring в IDE для запуска не требуются. Отдельные настройки `.idea` не входят в репозиторий и не нужны получателю.

## Создать ZIP для передачи

В PowerShell из корня исходников:

```powershell
.\scripts\package.ps1
```

Скрипт выполняет сборку с тестами и создаёт:

- `target/calendar-0.1.0.zip` — готовое приложение, два запускающих скрипта и инструкция;
- `target/calendar-0.1.0.zip.sha256` — контрольная сумма.

После уже выполненной успешной сборки можно указать `-SkipBuild`. В архив копируются только перечисленные файлы: база, кэш Maven, исходники, аккаунты GitHub и локальные настройки туда не попадают.

## Данные

При первом запуске создаётся **чистая H2-база** `data/calendar.mv.db`. Она хранит события: ID, название, предмет, тип, дату, время, место и описание. `data/event-groups.properties` хранит принадлежность ID другим группам; без отдельной записи событие относится к ТОП-105Б.

Для резервного копирования остановите приложение и сохраните **всю папку data**. Данные получателя сохраняются между запусками. Локальная база разработчика, секреты и временные файлы исключены из Git и выпуска.

Справочник групп включён в `src/main/resources/catalog/groups.txt`, источник — [расписание УУНиТ](https://isu.uust.ru/class_schedule/), снимок от 14.10.2026. Занятия автоматически не импортируются. Подробно о хранении — [docs/DATABASE.md](docs/DATABASE.md).

## Адрес и ограничения

По умолчанию приложение доступно только на компьютере запуска через localhost. Режим подключения к компьютеру прежнего владельца по сетевому адресу удалён. Мобильная разметка сохранена; [подробнее об интерфейсе](docs/PHONE.md).

Если порт занят, остановите другую копию приложения или задайте переменную `PORT`, например `$env:PORT='8081'` перед запуском. Тогда адрес — http://localhost:8081.

Входа пользователей, ролей, уведомлений и обновления в реальном времени пока нет. Локальный пользователь может выбрать любую группу и изменить её события. Для публикации в Интернете нужна отдельная настройка сервера, HTTPS и доступа. Такой публикации в этой поставке нет.

## API

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/api/groups` | Справочник, источник и дата снимка |
| GET | `/api/events` | События выбранной группы |
| POST | `/api/events` | Создание, HTTP 201 |
| PUT | `/api/events/{id}` | Изменение, HTTP 200 |
| DELETE | `/api/events/{id}` | Удаление, HTTP 204 |

Методы событий принимают параметр `?group=НАЗВАНИЕ` с URL-кодированием. Без него используется ТОП-105Б. Неизвестная группа — 400, событие другой группы — 404. Это разделение календарей, а не авторизация.

Типы событий: `TEST`, `CREDIT`, `EXAM`, `ACTIVITY`, `DEADLINE`. Обязательны название, предмет, тип и дата. Название — до 120 символов, предмет — до 100, место — до 120, описание — до 2000. Годы — 1900–9999; время необязательно.

Результаты проверки — [CHECKS.md](CHECKS.md). План развития — [docs/PLAN.md](docs/PLAN.md).
