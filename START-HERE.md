# Calendar 0.1.0 — запуск готового приложения

1. Установите **Java 25** (или более новую совместимую версию), если её ещё нет. Подойдут, например, OpenJDK или Microsoft Build of OpenJDK с официального сайта поставщика. Команда `java -version` должна работать; другой способ — задать `JAVA_HOME` на папку установленной Java.
2. Полностью распакуйте архив `calendar-0.1.0.zip` в отдельную папку. Не запускайте файлы прямо внутри ZIP.
3. **Windows:** дважды нажмите `run.cmd`. **macOS/Linux:** откройте терминал в распакованной папке и выполните `sh run.sh`.
4. Дождитесь строки `Started CalendarApplication` и откройте **http://localhost:8080** в браузере.

Окно запуска нужно оставить открытым. Остановка — Ctrl+C. IntelliJ, Maven, Node.js и отдельный сервер базы не требуются: Java-библиотеки уже находятся в `calendar.jar`. После установки Java для обычного запуска Интернет не нужен; список групп тоже входит в приложение. Java сама в архив не включена.

В исходной папке репозитория `run.cmd` / `sh run.sh` при отсутствии JAR сначала выполнят сборку. В этом случае нужен JDK 25 и Интернет для первой загрузки Maven и библиотек. Для передачи без сборки используйте именно ZIP из GitHub Releases, а не автоматически создаваемый GitHub архив Source code.

## Первое открытие

Получатель начинает с чистого календаря. База `data/calendar.mv.db` создаётся автоматически при запуске, а `data/event-groups.properties` — после первого события другой группы. В архиве нет базы прежнего владельца, паролей или личных настроек браузера.

Выберите группу сверху страницы и добавьте событие. Справочник содержит 3065 групп УУНиТ; основная группа — ТОП-105Б. Занятия из университетского расписания автоматически не импортируются.

Сохраняйте папку `data`: это ваши события. Для резервной копии остановите приложение и скопируйте её целиком. При обновлении приложения оставьте свою `data` на месте и замените файлы программы после остановки. Не запускайте одновременно две копии с одной папкой данных.

## Если запуск не удался

- `UnsupportedClassVersionError` — Java слишком старая, требуется 25 или новее.
- `Address already in use` / занят порт — закройте другую копию Calendar. Можно задать переменную `PORT` перед запуском, например в PowerShell: `$env:PORT='8081'; .\run.cmd`. Тогда адрес — http://localhost:8081.
- `JAVA_HOME` указывает на несуществующую папку — исправьте эту переменную либо удалите её и добавьте Java в `PATH`.
- Не закрывайте окно с ошибкой до её прочтения. Полный текст ошибки помогает определить причину.

## Границы этой версии

Приложение доступно на компьютере, где запущено, по адресу localhost. Отдельный режим подключения к компьютеру владельца по сетевому адресу удалён. Адаптивная разметка сохранена.

Авторизации, ролей и уведомлений нет. Локальный пользователь может менять события любой выбранной группы. Для общего доступа через Интернет потребуется отдельная настройка сервера, HTTPS и вход пользователей — они не входят в эту поставку.
